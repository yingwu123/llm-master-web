GPT-6 Pro终于开始推送：100美元、200美元Pro用户先上车

前天写完 GPT-6 Astra正式发布 后，录友问得最多的不是跑分，而是一句很直接的话：

我到底什么时候能在 ChatGPT 里用上 GPT-6？

现在有答案了。

截至北京时间 2026 年 9 月 5 日，由 GPT-6 Astra 驱动的 GPT-6 Pro 已经开始在 ChatGPT 中分批推送。

首批覆盖这几类用户：

  • ChatGPT Pro 5x，100 美元/月；
  • ChatGPT Pro 20x，200 美元/月；
  • 符合条件的 ChatGPT Business；
  • 符合条件并由管理员开启的 ChatGPT Enterprise。

截图里的重点就两个：Pro 用户已经开始收到推送，Plus 用户还要继续等灰度。

所以，如果你已经是 Pro，但模型列表里暂时没有 GPT-6 Pro，不代表账号有问题。OpenAI 用的是分批开放，不是同一秒给所有账号一起解锁。

GPT-6 Pro和GPT-6 Astra是什么关系？

这两个名字很容易让人误以为是两款模型。

简单理解：

  • GPT-6 Astra 是模型和 API 侧使用的名称；
  • GPT-6 Pro 是它在 ChatGPT 里的高算力使用方式，面向符合资格的付费套餐；
  • 订阅 ChatGPT Pro 不等于获得 API 余额，API 调用仍然单独计费。

GPT-6 Astra 的能力、Computer Use、上下文窗口、API 价格和完整评测，我已经在 GPT-6 Astra发布详解 里拆过了，这篇不再重复堆跑分。

这次真正值得关注的是：GPT-6 不再只是发布页和 API 文档里的名字，普通 Pro 用户已经开始拿到真实入口。

100美元和200美元Pro，模型有区别吗？

OpenAI 当前把个人 Pro 分成两个档位：

套餐 官方价格 主要区别 GPT-6 Pro开放情况
Pro 5x 100 美元/月 相比 Plus 提供约 5 倍的 Codex / Work 使用额度 正在分批推送
Pro 20x 200 美元/月 相比 Plus 提供约 20 倍使用额度，桌面端语音权益更高 正在分批推送

两档 Pro 的核心差别是使用额度，不是 100 美元拿到“缩水版 GPT-6”，200 美元才拿到“完整版 GPT-6”。

如果只是偶尔问几个复杂问题，100 美元档通常已经很重；如果你每天长时间跑 Codex、Computer Use、文档分析和多轮 Agent，20x 才更有意义。

别只因为“首发”两个字就无脑上 200 美元。GPT-6 Astra 很强，但重度推理、长上下文和工具调用也会更快消耗额度。套餐怎么选，还是看你每天是否真的有高强度任务。

Plus用户现在能不能用GPT-6？

这里要把不同产品入口分开说。

OpenAI 官方定价文档已经在 ChatGPT Work 和 Codex 的额度表中列出 GPT-6 Astra，Plus 也有对应额度；但这不等于 ChatGPT 对话里的 GPT-6 Pro 模式已经对所有 Plus 用户立即开放。

截至 9 月 5 日，ChatGPT 中 GPT-6 Pro 的首轮推送仍以 Pro 100 美元、Pro 200 美元和符合条件的 Business、Enterprise 为主。Plus 用户可能还要再等几天，具体以自己账号的模型选择器为准。

不要因为别人截图里有，你的账号里没有，就反复切地区、改支付方式或者找人“强开模型”。 灰度资格由 OpenAI 控制，第三方充值平台也不能跳过这个过程。

如果你的 ChatGPT 结账页可以正常使用官方支持的银行卡，优先直接订阅。没有海外信用卡，也不想折腾虚拟卡，可以查看 PayAI.plus 当前提供的 ChatGPT Pro 充值选项：

👉 前往 PayAI.plus 充值 ChatGPT Pro 20x（200美元档）

截至本文发布时，PayAI 页面显示 Pro 5x 和 Pro 20x 两个套餐，支持人民币支付。页面价格、库存、交付方式和售后规则都可能变化，下单前一定要再次核对套餐名称，别把 Plus、Pro 5x 和 Pro 20x 买混。

还要把边界说清楚：PayAI.plus 是第三方充值服务，不是 OpenAI 官方支付页面。完成 Pro 充值后，你拿到的是对应套餐资格；GPT-6 Pro 何时出现在模型列表里，仍然取决于 OpenAI 的账号灰度。

已经是Pro，为什么还看不到GPT-6 Pro？

先别急着重复付款，按下面顺序检查：

  1. 打开 ChatGPT 设置，确认当前套餐确实是 Pro 5x 或 Pro 20x；
  2. 新建一个对话，再检查模型选择器；
  3. 退出并重新登录 ChatGPT，或者更新桌面端 App；
  4. 如果是 Business、Enterprise，确认工作区管理员是否已经开放 Astra；
  5. 仍然没有，就等灰度，不要为了刷新资格重复充值。

Enterprise 还多一层管理员控制。OpenAI 官方工作区文档说明，Astra 在 Enterprise 首轮开放期间默认关闭，符合资格的组织需要由管理员为用户或用户组开启。

所以同一家公司的两个账号，一个能看到、一个看不到，也可能只是工作区设置不同。

现在值得为了GPT-6升级Pro吗？

如果你只是日常聊天、翻译、写短文，没必要为了抢几天首发立刻升级。

但如果你每天都在用 AI 写代码、分析大文件、操作浏览器、处理表格，或者跑几个小时的长链路 Agent，GPT-6 Astra 的电脑操作和工具调用能力才真正有价值。

我的建议很简单：

  • 偶尔重度使用，先看 Pro 5x；
  • 每天持续跑 Codex 和 Work，再考虑 Pro 20x；
  • 只想尝鲜，而且不着急，继续等 Plus 灰度最省钱。

已经确定要升级的录友，可以直接去 PayAI.plus 的 ChatGPT Pro 充值页 看当前套餐。

GPT-6 Pro 已经开始上车了。真正需要它的人，别买错档；只想围观的人，也别被首发焦虑推着花钱。
